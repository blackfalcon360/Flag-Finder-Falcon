# Flag Finder — دنیا کے جھنڈے

Android app: shows the flags of all countries; select the colors you see in a flag and the app lists the matching countries.
اینڈرائیڈ ایپ: تمام ممالک کے جھنڈے دکھاتی ہے؛ جھنڈے میں نظر آنے والے رنگ منتخب کریں تو متعلقہ ممالک سامنے آ جاتے ہیں۔

## Features
- ~197 countries (flags shown as emoji — no internet or image files needed)
- 8 color chips: Red, White, Blue, Green, Yellow, Black, Orange, Light Blue
- Default: shows flags that contain ALL selected colors (closest matches first)
- "Only these colors" option: exact match
- Country names in English and Urdu

## Build the APK with GitHub
1. Create a new GitHub repository and upload everything in this folder.
2. Open the **Actions** tab → **Build APK** (it runs automatically on every push).
3. When it finishes, download **FlagFinder-debug-apk** from the run's Artifacts, unzip it and install the APK.

Or locally with Android Studio: open the folder and run the `app` module.
